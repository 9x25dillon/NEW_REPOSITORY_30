Standing-wave simulation

Compare fluid-sphere radiation models and follow particles with independent fluid advection. Save the complete description to reproduce a run.

This is a model benchmark. It assumes an isolated fluid sphere, linear acoustics, and overdamped Stokes drag. Plate streaming uses an outer slip approximation; walls do not modify the radiation force or drag.

Edit frequency, pressure, particle radius, or the model choices. Radiation: mie or gorkov. Disable advection with "streaming": { "kind": "none" }. The example inputs are all assumed.
